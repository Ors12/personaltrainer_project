# Személyi edző portfólió – Szilasi Boldizsár

Bemutató weboldal egy személyi edző számára. Saját fejlesztés (ORSBUILDS), tiszta HTML/CSS/JavaScript, keretrendszer és build lépés nélkül.

## Mappaszerkezet

```
personaltrainer_project/
├── index.html        – az oldal tartalma és szerkezete
├── css/
│   └── style.css     – stílusok
├── js/
│   └── script.js     – interakciók
└── assets/
    └── images/       – saját képek helye
```

## Helyi futtatás

Nyisd meg az `index.html`-t böngészőben, vagy indíts egy egyszerű szervert:

```bash
npx serve .
```

## Telepítés

Statikus oldal, közvetlenül telepíthető Vercelre (build parancs nem kell).
